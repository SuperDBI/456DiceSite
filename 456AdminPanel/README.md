# 456Dice Admin Panel

This is the admin panel for managing the 456Dice.com website. It allows administrators to control frontend settings, backend features, user management, purchase records, security settings, and AWS resources.

## Features
- Manage frontend and backend settings
- User management
- Purchase and rewards tracking
- Security and privacy settings
- AWS resource monitoring

## Deployment
This project is Dockerized and ready for deployment on AWS using ECR and ECS.

## Setup
1. Clone the repository.
2. Build and run the Docker container.
3. Configure the connection to the AWS RDS PostgreSQL database.
